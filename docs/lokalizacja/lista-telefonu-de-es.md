# Lista telefonu: de, es (sesja AK, 2026-11-09, D-393)

Wzór: `lista-telefonu-4.md`. Każdy punkt: telefon w danym języku (Ustawienia → Ogólne → Język i region) albo ręczny wybór w aplikacji (Ustawienia → Język). Wynik zapisz przy punkcie: OK / błąd + zrzut.

- **T-d-1** Telefon de: pod ikoną „PokerGym”; powitanie; lekcja m0.l1 po niemiecku; „Straße” (strit) i „Street” (ulica) bez pomyłki; forma „du”.
- **T-d-2** Liczby w de: „1.000”, „0,5”, „50 %” (spacja przed %).
- **T-d-3** Przyciski przy XXXL i ekranie 320 pt (iPhone SE): długie złożenia („Einstufungstest”, „Mit dem Lernen beginnen”, zakładka „Wiederholungen”) bez obcięcia.
- **T-e-1** Telefon es-ES i es-MX (region Meksyk) → oba po hiszpańsku; przycisk „Igualo”; pytania z „¿…?”; „ciega grande”.
- **T-e-2** es: lekcja m3 lub m5 — „igualar” (nie „pagar”) przy zagraniu call; „pareja mayor” przy top pair.
- **T-5-1** Ramka „Odpowiedzialna gra” (m12-l4) i ekran Pomoc w de („Hilfe”) i es («Ayuda»): numery pomocy widoczne, link działa.
- **T-5-2** Zmiana języka w Ustawieniach pl → de → es → pl bez restartu; postęp bez zmian.
