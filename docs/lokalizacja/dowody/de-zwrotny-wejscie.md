# Wejście do kontroli przekładem zwrotnym (bez tekstu polskiego)

Kontekst: nazwy akcji pokerowych na ekranie treningu rozdań (Texas Hold’em, aplikacja do nauki). Znak U+00A0 zapisany jako `␣`.


## de

| klucz | tekst |
|---|---|
| fold | Fold |
| check | Check |
| call | Call |
| limp | Limp |
| raise | Raise |
| threeBet | 3-Bet |
| allIn | All-in |
| betSmall | kleine C-Bet |
| betBig | große C-Bet |
| amountPay | 1.5␣bb |
| amountTo | auf 2.5␣bb |
| amountAll | 10␣bb |
| raiseTo | Raise auf 2.5␣bb |
| callPay | Call 1.5␣bb |
| allInAmount | All-in 10␣bb |
| verdict | Deine Wahl: Call 1.5␣bb. Besser: Raise auf 2.5␣bb. |
