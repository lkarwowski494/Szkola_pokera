ポーカーのフィードバックは、しばしば嘘をつきます。良い判断が負けることもあれば、悪い判断が勝つこともあります。結果でプレイを評価すると、ランダムな信号から学ぶことになります。

## リザルティング：結果による評価

プレイヤーはこれを*リザルティング*と呼びます。結果の質が判断の質を示していると思い込むことです。心理学者は同じ現象を**結果バイアス**と呼んでいます。古典的な心理学の研究（1988年）では、結果が好ましいとき、人は同じ判断をより良いものと評価し、判断した人をより有能だと評価しました。結果を考慮に入れるべきではないと本人が考えていた場合でも、そうしていたのです。

## 良い判断でも負ける

キングの{{t:pair|ペア}}に対してエースの{{t:pair|ペア}}でオールインするのは最善の判断ですが、それでも約**{{n:res.kk-wins}}**のケースで負けます。一方、ターンで{{t:flush-draw|フラッシュドロー}}を持ち、{{t:pot|ポット}}全額に対して{{t:call}}するのは悪い判断です（必要なのは{{n:eq.bet-pot}}、あるのは約{{n:odds.flush.turn-river}}）。それでも、およそ5回に1回は勝ちます。

```formula
判断の質 = 判断した時点で持っていた情報のもとでのEV
```

## ハンドの分析方法

1. 結果を隠します。判断した時点で知っていたことだけを評価します。
2. 価格と、相手の{{t:range|レンジ}}に対するエクイティを計算します（M2、M6）。
3. プレイがコースのルールに沿っているか確認します。
4. 勝ったハンドも分析します。報われたミスも、同じだけコストがかかります。

## 結果が意味を持ち始めるとき

約{{n:skill.sample.m}}百万のオンラインハンドを対象にした研究（2015年の研究）では、スキルが運を上回り始めたのは約**{{n:skill.hands}}**ハンド後になってからでした。これは、上位{{n:skill.pct}}のプレイヤーが、約{{n:skill.ahead}}の比較で下位{{n:skill.pct}}を上回ったという意味です。スキル差がもっと小さければ、何倍ものハンドが必要です。そのため、数回の{{t:session|セッション}}の結果では、どのプレイスタイルが良いかはわかりません。

:::note このアプリでの評価
そのため、このアプリはハンドの結果ではなく、あなたの判断を評価します。結果と判断が食い違うときは、計算を信じましょう。
:::
